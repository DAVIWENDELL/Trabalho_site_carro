# Site de Veículos

Site responsivo de apresentação e compra de veículos, desenvolvido com HTML, CSS, JavaScript e Bootstrap.

## O que o projeto demonstra

- Página inicial;
- Apresentação de veículos;
- Páginas de detalhes e compra;
- Navegação responsiva.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Como executar

Abra `inicial.html` em um navegador ou use um servidor local.
